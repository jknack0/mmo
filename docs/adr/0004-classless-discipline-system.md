# Classless: 2-discipline mixing with per-discipline passive trees

There are no classes. Players learn **disciplines** (themed skill sets like Pyromancy, Blademaster) from in-world trainers and equip exactly 2 at a time. Build identity comes from four axes: which 2 disciplines, which 6 of 24 available skills are slotted, tripod choices per skill, and per-discipline passive trees (~20 nodes each with boosts, synergies, and keystones). The classless model is the deliberate departure from both Lost Ark and D2 — chosen because emergent classless archetypes are the historical soul of MMOs (UO, Asheron's Call) and create the kind of build-experimentation depth that solo-developed content can't match through sheer content volume. Cost: balancing combinations is significantly harder than balancing classes, and a "mathematically optimal pair" trap is the constant risk. Mitigation: tripods + items + passive keystones create enough intra-build variety that no single pair dominates if balance is intentional.
