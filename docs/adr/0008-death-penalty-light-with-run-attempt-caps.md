# Death penalty: no XP loss, light gold cost, run-attempt caps in instances

Softcore death never costs XP. Open-world death costs a small gear durability hit (gold to repair). Rifts impose a 3-deaths-per-run cap — the 4th death fails the run (no boss reward, but wave-clear materials are kept). Trials use standard raid-wipe rules with no extra external penalty beyond the run attempt itself. Hardcore (opt-in permadeath) is deferred to post-launch as additive scope. The deliberate departure from D2 is the no-XP-loss rule: D2's XP loss at high tiers made high-level deaths catastrophic and pushed players away from engaging with hard content. We want players to *want* to attempt the hardest Trial, even knowing they'll wipe — the cost of failure is the run attempt, not character progression. Death is given weight by run-internal consequences (Rift cap, Trial reset) and by gear durability, not by character regression.
